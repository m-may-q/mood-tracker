# Трекер настрою (mood-tracker)

Навчальний проєкт з курсу «Програмування веб-застосувань», 2 курс ФІОТ КПІ.

Варіант 3 — Трекер настрою та емоцій.

## Структура проєкту

```
mood-tracker/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
├── assets/
│   └── img/
├── .gitignore
└── README.md
```

## Заплановані розділи сторінки

- Шапка з назвою застосунку
- Форма відмітки поточного настрою
- Блок історії записів за датами
- Блок простої статистики
- Підвал

## Стан

Практична робота №1: обрано інструменти розробки, створено базовий HTML5-каркас сторінки.
